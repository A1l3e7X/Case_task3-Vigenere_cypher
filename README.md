# Case_task3-Vigenere_cypher
#Кейс-задача: шифр Виженера
# Шифрование текста шифром Вижинера в Excel с помощью Python и xlwings

## Описание решения задачи:

Пример макроса для шифрования текста с помощью “шифра Виженера” в среде “Microsoft Excel” с использованием языка “Python” и библиотеки “xlwings”.

Макрос запускается непосредственно из Excel через add-in “xlwings”, считывает исходный текст и ключевое слово из ячеек книги, выполняет шифрование и записывает результат обратно в Excel.

## Назначение макроса:

Назначение макроса — реализовать шифрование текста по алгоритму Вижинера так, чтобы:
- исходный текст вводился в Excel;
- ключевое слово задавалось в Excel;
- запуск выполнялся из Excel;
- результат автоматически записывался в нужную ячейку.

## Используемые технологии:

- “Python”
- “xlwings”
- “Microsoft Excel”
- “шифр Виженера”

## Структура решения задачи:

Решение задачи состоит из двух основных файлов:

### 1. Excel-файл:
Книга Excel содержит:
- **B3** — исходный текст;
- **B4** — зашифрованный текст;
- **B5** — ключевое слово.

### 2. Python-файл:
Python-модуль содержит:
- русский алфавит;
- функцию шифрования “vigenere_encrypt()”;
- функцию “main()”, запускаемую из Excel через “xlwing”.

## Принцип работы программы:

После запуска из Excel программа:
1. получает текущую открытую книгу;
2. переходит к листу **Шифрование**;
3. считывает текст из ячейки **B3**;
4. считывает ключ из ячейки **B5**;
5. шифрует текст по алгоритму Виженера;
6. записывает результат в ячейку **B4**;
7. подсвечивает ячейку результата.

## Принцип шифрования:

В программе используется русский алфавит из 33 букв:

“АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ”

Для каждой буквы текста:
1. определяется её позиция в алфавите;
2. определяется позиция соответствующей буквы ключа;
3. позиции складываются;
4. результат берётся по модулю длины алфавита;
5. получается новая буква шифртекста.

Символы, которые не относятся к русскому алфавиту, не изменяются.

##Объяснение кода программы:

### Шаг 1. Импорт библиотеки xlwings:

В начале программы подключается библиотека:

```python
import xlwings as xw
Она необходима для взаимодействия Python с Excel.

### Шаг 2. Задание алфавита:
В коде задаётся строка русского алфавита:
ALPHABET = "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"
Эта строка используется для поиска позиций букв при шифровании.

###Шаг 3. Функция шифрования:
Основная логика реализована в функции:
def vigenere_encrypt(text: str, key: str) -> str:
Она принимает:
•	text — исходный текст; 
•	key — ключевое слово. 
Функция возвращает зашифрованную строку.

###Шаг 4. Проверка ключа:
В начале функции выполняется проверка:
if not key:
    return text
Если ключ не введён, функция возвращает текст без изменений.

###Шаг 5. Подготовка переменных:
Далее в функции создаются рабочие переменные:
result = []
key = key.upper()
key_index = 0
Они нужны для:
•	накопления результата; 
•	перевода ключа в единый регистр; 
•	отслеживания текущей позиции в ключе. 

###Шаг 6. Обработка текста посимвольно:
Программа перебирает каждый символ текста:
for ch in text:
    upper_ch = ch.upper()
Это позволяет отдельно обработать каждую букву и сохранить прочие символы без изменений.

###Шаг 7. Проверка, является ли символ русской буквой:
Если текущий символ содержится в русском алфавите, он шифруется:
if upper_ch in ALPHABET:
Если символ не является русской буквой, он просто переносится в результат.

###Шаг 8. Определение позиции буквы текста:
Для букв определяется их номер в алфавите:
text_pos = ALPHABET.index(upper_ch)

###Шаг 9. Определение позиции буквы ключа:
Далее определяется позиция соответствующей буквы ключа:
key_pos = ALPHABET.index(key[key_index % len(key)])
Оператор % позволяет повторять ключ по кругу до конца текста.

###Шаг 10. Вычисление зашифрованной буквы:
Зашифрованная буква вычисляется по формуле Виженера:
cipher_char = ALPHABET[(text_pos + key_pos) % len(ALPHABET)]
Это реализация формулы:
C = (P + K) mod m
где:
•	P — позиция буквы текста; 
•	K — позиция буквы ключа; 
•	m — длина алфавита. 

###Шаг 11. Сохранение регистра:
Если исходная буква была строчной, программа делает строчной и зашифрованную букву:
if ch.islower():
    cipher_char = cipher_char.lower()
Это сохраняет внешний вид текста.

###Шаг 12. Добавление символа в результат:
После вычисления символ добавляется в список результата:
result.append(cipher_char)
Затем увеличивается индекс ключа:
key_index += 1

###Шаг 13. Обработка небуквенных символов:
Если символ не относится к русским буквам, он не шифруется:
else:
    result.append(ch)
Так в тексте сохраняются:
•	пробелы; 
•	запятые; 
•	точки; 
•	тире; 
•	кавычки; 
•	цифры. 

###Шаг 14. Формирование итоговой строки:
После обработки всех символов результат собирается в строку:
return "".join(result)

###Шаг 15. Функция main():
Для запуска из Excel используется функция:
def main():
Именно её вызывает кнопка Run add-in xlwings.

###Шаг 16. Получение текущей книги Excel:
Внутри main() выполняется:
wb = xw.Book.caller()
Это позволяет программе получить доступ именно к той книге Excel, из которой она была запущена.

Далее программа обращается к листу:
ws = wb.sheets["Шифрование"]

###Шаг 17. Чтение текста и ключа:
После этого считываются данные из Excel:
source_text = ws.range("B3").value or ""
key = ws.range("B5").value or ""
Здесь:
•	B3 — исходный текст; 
•	B5 — ключ. 

###Шаг 18. Вызов шифрования:
Затем вызывается функция шифрования:
encrypted_text = vigenere_encrypt(source_text, key)

###Шаг 19. Запись результата в Excel:
Готовый шифртекст записывается в ячейку:
ws.range("B4").value = encrypted_text

В конце программа делает цветную подсветку ячейки с результатом:
ws.range("B4").color = (255, 242, 204)
